# Table Talk

Created by [henrymeihao](https://github.com/henrymeihao).

短期旅行场景英语学习网站，包含餐厅、咖啡店、面包甜品店、Brunch、Pub、鸡尾酒吧、酒店入住、行李寄存、地铁公交和城际火车，共 10 个主题。

提供实用接话、语法、词语与例句朗读、输出与迁移练习，以及按日期保存的复习记录。

## 运行与发布

需要 Node.js 18+，无需安装第三方运行依赖。

```sh
npm run build
npm test
npm start
```

浏览器打开 http://127.0.0.1:4318 。构建产生 dist/（预览）和 docs/（GitHub Pages）。Pages 使用 main 分支的 /docs 目录；修改后重新构建并提交 docs/ 即可更新。

## 学习记录与隐私

回答、收藏、自评、复习日期和阅读位置仅保存在访问者当前浏览器。同一网址下再次进入可继续使用，不同访问者各自保存。清除网站数据、使用无痕模式、换浏览器、设备或网址时，旧记录不会自动同步。

首页可导出进度 JSON，并从文件或文本恢复。从其他网站迁移时，先在旧站导出，再在本站恢复。备份包含练习回答，请自行保管。

朗读使用设备合成语音；部分系统语音可能联网。课程姓名和情境为虚构练习，网页保留开发者署名，不展示联系邮箱或本机路径。

公开仓库使用清理后的新提交历史，不包含早期私有项目的 Git 历史、托管凭证或学习记录。
